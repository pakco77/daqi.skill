# 用户旅程：低摩擦版

> 每个阶段的摩擦都拆在进门之前。

## 1 · 第一次安装

一条命令装好三件套（daqi / context-fold / project-fold）。第一次使用只问两件事：**中文还是英文、新项目默认放哪**——都可以「稍后设置」。营地 `~/.daqi` 建好：账本空、马厩空、火堆旁还没有你的画像。

## 2 · 可视化看板：打开营地

一句「**进营地**」，浏览器直接打开营地页——离线、自包含、昼夜两套配色、火是唯一的颜色。

营地支持**先扫描本地 Agent**：说「扫描」→ 达奇扫 DSH / Claude Code / Codex 的会话元数据（只读 cwd+时间戳，**不读对话**）→ 列出工作区候选 → 你指定扫描哪些 → 点子、计划、马厩一起捞回来（shallow 免费，deep 走 DeepSeek 大脑，丰俭由人）。

看板四块，各有一句话解释：
- **情报**＝痛点，先盯着
- **点子**＝想法，慢慢养
- **计划**＝证据齐了，等你拍板
- **马厩**＝在跑的项目，每匹带主线

## 3 · 点子自动孵化机制：对话自动触发

不用记命令。你说「我发现……」「有个痛点……」「我想做……」「我有个想法……」，达奇自己触发：情报/点子自动进账本、自动去重、自动挂钩。点子上证据、有用户、有交付物、有验证 → 升为计划 → 达奇只问一句「**开干吗**」。

## 4 · 跨 Agent 机制：点子生命周期同步

营地是三个本地文件，不是某个会话的私有记忆。任何 Agent 装上 skill，读的是同一份账本、同一个马厩：

- 换 Agent 说「达奇：开工」→ 一条主线、一个下一步，不用重新解释
- 点子从情报→点子→计划→马厩的每一步，在哪个 Agent 里发生都落在同一本账上
- Codex 更省事：一次精确根设置后，开工自动注入、收工自动存档

## 5 · 预设快捷指令

给不同 Agent 的固定入口，到处都能用：

| 指令 | 干什么 | 备注 |
|---|---|---|
| `/daqi-search` | 扫描点子：列候选 → 指定 Agent 历史 → 提炼候选 + token | 只读，确认才入库 |
| `/daqi-camp` | 打开营地面板 | macOS 自动开浏览器 |
| `/daqi-deep <项目>` | 深挖项目进程 | **长耗时**：进度线 + 营地页进度条；无 key 自动降级 |
