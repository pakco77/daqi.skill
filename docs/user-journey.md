# 用户旅程：以达奇为例

> 一个点子王的八个时刻。全程只读对话、只写你点头的东西。

## 时刻 0 · 第一次见面

你在新 Agent 里说「安装 daqi」→ 三件套（daqi / context-fold / project-fold）装好。
第一次使用时，达奇只问两件事：**中文还是 English？新项目默认放哪？**（都可以「稍后设置」。）
你说「中文，~/Projects」。营地 `~/.daqi` 建好，账本空、马厩空、火堆旁还没有你的画像。

## 时刻 1 · 第一条情报

你随口说：「我发现每次换 Agent 都要重新解释项目。」
达奇：「**点子王**，情报记进账本了。有风声、还没方向；先盯着，不急。」
——「点子王」三个字只在你的点子出现的瞬间出现：这是达奇在场的证明。

## 时刻 2 · 第一个点子

你说：「我想做一个跨 Agent 的复盘工具。」
达奇查账本：这条和刚才的情报有关 → 把情报挂到点子上，不重复记。
回你：「点子记账了。手上 X 还没落地；这个先压着？」

## 时刻 3 · 盘点

你说「盘点」。营地页 `~/.daqi/camp.html` 生成：
账本（情报 · 点子 · 计划）、马厩（在跑 / 松了 / 歇马，每匹带可确认的当前进度）、中央的火（观火观己——达奇对你的画像）。
账本里有达奇的形象，马厩里有摩根在看马，每 6 秒换一句实况。

## 时刻 4 · 点子成熟

证据齐了。达奇：「计划成型了：谁用、交出什么、怎么验，都清楚。出发，还是再养养？」
你说「**立项**」。达奇才建文件夹骨架（00_Context / 10_Source / 20_Docs / 90_History）、把项目放进马厩、写下第一版 NOW 主线。立项权永远在你手里。

## 时刻 5 · 老项目进营

你说「**扫描**」——达奇扫 DSH / Claude Code / Codex 的会话元数据（只读 cwd+时间戳，**不读对话**），列出工作区候选，你勾选、深读（shallow 免费 / deep 走 DeepSeek 大脑，丰俭由人），点子和项目一起捞回来，确认后才入库。
没主线的马，说「**补主线**」——出候选四字段，你点头才写。

## 时刻 6 · 换 Agent，不重讲

你在另一个 Agent 里说「达奇：开工」：
> 我有一个计划。你在推 **X**（上次到 Y）。下一步：Z。

三个文件里的一切都在。Codex 上更省事：一次精确根设置后，开工自动注入 NOW、收工自动存档。

## 时刻 7 · 回来的地方

营地页就是家：账本、马厩、观火观己、扫描、一键整理，全部离线、自包含。
火是唯一的颜色。达奇不会背叛你——你的每一条点子，都在账本里。
